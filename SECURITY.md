# Security Policy

This repository contains a static educational website (built with Quarto). We do not process untrusted user input or run a server. Security risk is therefore minimal, but we still welcome responsible reports.

## Reporting a vulnerability
- If **Private Vulnerability Reporting** is enabled on GitHub for this repository, please use the **Security → Report a vulnerability** link.
- Otherwise, open an issue with the label `security`, or contact the maintainer listed in the README.

Please include as much detail as possible (steps to reproduce, affected files/URLs). We will acknowledge receipt within a reasonable time and keep you updated on remediation.

## Supported versions
We support the `main` branch only. If you are using a fork or archived release, please upgrade to the latest `main` commit.

## Disclosure
Do not publicly disclose potential vulnerabilities until we have had a chance to investigate and release a fix.
