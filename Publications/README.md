# Publications Archive

This folder contains public abstract/poster materials and analysis source code related
to the Code Blue and Rapid Response training work. It is not part of the learner-facing
Quarto site.

Do not commit row-level course-evaluation data, REDCap exports, survey PDFs, local
analysis workbooks, draft abstract files, editable poster decks, or generated render
folders. The public branch should keep DOI/citation metadata, safe aggregate artifacts,
and source code that clearly documents which restricted local inputs are required.

Current public scholarly records:

- 2025 ATS abstract: DOI `10.1164/ajrccm.2025.211.abstracts.a5624`.
- 2026 ATS abstract/poster: DOI `10.1093/ajrccm/aamag162.939`.
