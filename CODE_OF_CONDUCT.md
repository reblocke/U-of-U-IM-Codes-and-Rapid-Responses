# Code of Conduct (summary adoption)

This project adopts the **Contributor Covenant, version 2.1**. We are committed to a harassment‑free, inclusive community. Expected behavior includes kindness, respectful discussion, and constructive feedback. Unacceptable behavior includes harassment, discrimination, or personal attacks.

**Enforcement & reporting:** If you experience or witness unacceptable behavior, please contact the maintainers (open an issue or contact the maintainer listed in the README). Reports will be reviewed and addressed promptly and confidentially to the extent possible.

For the complete text, see the Contributor Covenant v2.1:  
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

> This file summarizes and adopts the Contributor Covenant. Projects that require the full legal text should replace this file with the full v2.1 text and add an email address or reporting contact.
